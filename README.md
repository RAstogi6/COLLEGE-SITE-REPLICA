# 🎓 College Examination Dashboard Replica

A responsive, pixel-perfect frontend replica of a university/college examination ERP dashboard.

> ⚠️ **DISCLAIMER:**  
> This project is created **strictly for educational, portfolio, and harmless prank/demonstration purposes**. It is a static frontend UI clone designed to demonstrate modern web design and DOM manipulation skills. It does **not** connect to real backend databases, alter real academic records, or pose any security risk.

---

## ✨ Features

- **Dashboard Overview:** Displays semester cards with SGPA, credits earned, status badges, and publish dates.
- **Interactive Action Menu:** 3-dot menu with expandable sub-options for viewing specific exam attempt results.
- **Annual Examination View:** Switch seamlessly between **Semester** and **Annual** views with calculated YGPA and aggregate summary statistics.
- **Detailed Examination Result Page:** Comprehensive subject-wise marks table featuring:
  - Theory & Lab subject categorization badges
  - Mid-Term 1, Mid-Term 2, and End-Term mark breakdowns
  - External and Internal mark tallies
  - Dynamic grade badges (`A+`, `A`, `B+`, `B`, `C`, `E#`)
  - Overall summary calculations
- **Fully Responsive & Clean Theme:** Modern light-mode styling inspired by modern college ERP portals.

---

## 🛠️ Built With

- **HTML5** – Semantic markup and layout structure
- **Vanilla CSS3** – Custom responsive styling, dynamic flex/grid layouts, CSS variables, and animation transitions
- **JavaScript (ES6+)** – Interactive dropdown logic, view toggles, and dynamic parameter-driven result page population
- **Google Material Symbols** – Modern vector icon system
